# humux — Human Multiplexer

> A squad of AI agents that acts like a full team of experts at your disposal. Self-hosted, one Docker container.

humux is an open-source, self-hosted squad of AI agents — a lead, a developer, a researcher, a marketer, a QA — that pick up your most ambitious ideas, do the work, and report back. They coordinate via GitHub issues, each with their own identity, tools, model, and voice, all running on your own hardware under your own API keys.

The foundation underneath is a full personal assistant: it triages your email, manages your calendar, sends morning briefings, handles your messages, and runs scheduled tasks — with no cloud AI dependencies.

## What makes it different

- Email, calendar, and contacts are built in — not via third-party plugins
- Multi-agent squads that coordinate work via GitHub issues, each with their own GitHub App identity
- Skills system: teach the agent new CLI tools by writing markdown files, no code
- Encrypted two-tier secrets vault (infra keys + agent secrets) — credentials never enter the LLM context
- Multiple agents with per-agent Telegram bots, voice, email accounts, and tool scopes
- Four-tier memory: lexical retrieval, semantic search, importance-based forgetting, deduplication
- Single container deployment — SQLite, no external databases, no Kubernetes

## Quick start

```bash
docker run -d --name humux -p 8000:8000 -v ./data:/app/data ghcr.io/mattmezza/humux:latest
```

Admin UI at http://localhost:8000 — setup wizard guides through LLM API key, Telegram bot, and agent configuration.

## Capabilities

- Messaging: Telegram (per-agent bots, voice, reactions, inline approvals, multi-message replies), WhatsApp, CLI
- Live transcript: /weburl returns a read-only, live-updating web page of that chat — reasoning and tool calls behind expandable chips, no login for the reader
- Email: read, compose, search, manage — per-agent mailboxes with vault-secured credentials
- Calendar: CalDAV (Google Calendar, iCloud, Fastmail) — read/write events, scheduled briefings
- Contacts: CardDAV + Google Contacts — search, create, per-agent access levels
- GitHub: webhook-driven agent turns on issues/PRs/comments, multi-agent routing, per-agent GitHub App identity
- Voice: STT via faster-whisper or remote OpenAI-compatible API, TTS via edge-tts / Kokoro / remote TTS
- Memory: four-tier system with automatic extraction from conversations
- Skills: markdown-based, installable from git repos via admin UI
- Subagents: scoped sub-tasks with per-spawn step/token/thinking budgets and an optional different model/provider; spawn_subagents fans several out in parallel; per-agent delegation trust lists (spawnable_agents); the agent itself reads the results and replies when a background batch lands
- Deep research: multi-step autonomous research pipeline — plan, search, fetch, verify, synthesize a cited report as a shareable artifact
- Browser: headless Playwright with persistent profiles and per-domain rules, optional sidecar
- Coding: read/write/edit/bash tools confined to workspace directory
- Scheduling: cron-based jobs for briefings, email checks, custom tasks — pause and resume via admin UI
- Security: ALWAYS/ASK/NEVER permission rules, Telegram inline approval buttons, YOLO mode default
- Admin UI: PWA-installable, token usage dashboard (24h/7d/30d), per-agent LLM override, mid-turn steering, Inspect tab (exact last-sent LLM payload per context + live subagent run tree)
- Artifacts: agent-generated web apps and pages served under /artifacts/ with shareable links

## LLM providers

Anthropic, OpenAI, Google Gemini, Grok (xAI), DeepSeek, OpenRouter — configurable per-agent.
